# Requirements

## 1. Customer Requirements

- Customer can register an account.
- Customer can login and logout.
- Customer can view restaurants.
- Customer can view food items.
- Customer can search for food.
- Customer can add food items to cart.
- Customer can update cart quantity.
- Customer can remove items from cart.
- Customer can place an order.
- Customer can view order history.
- Customer can track order status.

## 2. Restaurant Requirements

- Restaurant can login.
- Restaurant can add food items.
- Restaurant can update food items.
- Restaurant can delete food items.
- Restaurant can view customer orders.
- Restaurant can accept or reject orders.
- Restaurant can update order status.

## 3. Delivery Partner Requirements

- Delivery partner can login.
- Delivery partner can view assigned orders.
- Delivery partner can accept delivery.
- Delivery partner can update delivery status.
- Delivery partner can view delivery details.

## 4. Admin Requirements

- Admin can login.
- Admin can manage customers.
- Admin can manage restaurants.
- Admin can manage delivery partners.
- Admin can view all orders.

## 5. General Requirements

- The system should provide secure login.
- The system should store data in a database.
- The system should provide a simple and user-friendly interface.
- The system should maintain order and delivery information correctly.
